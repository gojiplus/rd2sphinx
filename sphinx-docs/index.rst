rd2sphinx
=========

Converts R documentation ('Rd') topics into semantic Sphinx source
files. The package bundles a small Sphinx domain for R functions, data, and
help topics, so the generated objects participate in cross-references,
search, inventories, and any Sphinx theme, including 'Furo'. It also
scaffolds and runs a conventional Sphinx build pipeline.
